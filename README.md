# 天津鼓楼资料数据库（Gulou Archive）

围绕天津鼓楼历史、特别是 **1920—1921 年鼓楼重修** 的多源互证研究资料库。汇集报纸原版面、档案馆目录与开放全文、清末及民国照片、方志城图和历史地图，并以关系图谱、事件时间轴和条目详情组织证据链。

当前整理版本：**v1.0.0（2026-11-19）**。公开层共 **46 条记录**。

## 公开内容

- **报纸报道 13 条**：《大公报》《益世报》1920—1921 年原版面，含转录、逐条校勘、整版影像与精读裁切。
- **天津市档案馆史料 5 条**：1911 年鼓楼进香案卷，以及 1922 年落成拈香、1946 年修筑捐款、移交保护和阅报栏挪移等目录记录。
- **老照片**：清末旧楼与 1921 年重建后新楼。
- **方志城图与地图**：康熙《天津卫志》城图、1899 年《天津城厢保甲全图》、1913 年天津地图等。
- **附表与研究数据**：全国 30 处鼓楼存毁状态表、研究文献总表。
- **关系图谱与事件时间轴**：节点关联到资料条目，并标注证据等级。

### 档案馆史料的全文状态

1911 年案卷 `401206800-J0128-3-002584` 已收录与鼓楼直接相关的 `-041`、`-042`、`-043` 三件开放全文，共 **3 份 PDF、7 页 JPG**；下载来源、页码、文件大小和 SHA-256 校验值保存在对应目录的 `download_manifest.json` 中。

其余 4 条均为“目录已核实；开放全文未收录，原件待调”。目录题名只能证明该条目已经著录，不代替原文，也不据此推断档案内文的具体事实。

## 本地运行

要求 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

开发服务器支持在命令后转发主机和端口参数，例如：

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

## 校验与构建

```bash
npm run check
npm run build
npm run preview
```

- `npm run check` 检查条目编号唯一性、公开附件路径及本地文件是否齐全。
- `npm run build` 生成完整静态网站到 `dist/`。
- 所有公开附件均从 `public/` 复制到发布包，主站与附件同源，不依赖外部附件站。
- 网站使用哈希路由，普通静态托管无需额外的服务端路由规则。

## 数据与目录

```text
public/assets/       公开影像、文献、表格及档案下载清单
src/data.js          公开条目数据
src/knowledge.js     关系图谱与时间轴
src/main.js          页面、检索与详情交互
scripts/             公开数据校验脚本
```

本仓库只包含公开层。维护者本机的 `assets-private/`、`src/data.private.js`、本地维护脚本和环境配置均由 `.gitignore` 排除，不属于开源内容。私有资料包括当代版权扫描件和未发表手稿，不应复制进公开目录或提交到仓库。

## 部署

将 `dist/` 整体上传至静态网站托管服务即可。附件目录包含中文路径，托管平台必须保留 UTF-8 文件名；不要只上传 `index.html` 和打包后的 JavaScript。

平台默认域名可用于初步发布和测试，但其访问限制、费用与使用条款以平台当前说明为准。本次发布使用腾讯云 CloudBase 免费体验环境，默认域名可能先显示访问提示，免费期届满后需按平台规则续期；不应视为永久稳定的存档网址。论文中长期引用时，应记录实际访问日期和发布版本。
